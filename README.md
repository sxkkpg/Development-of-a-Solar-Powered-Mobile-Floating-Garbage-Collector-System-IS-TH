# Development-of-a-Solar-Powered-Mobile-Floating-Garbage-Collector-System-IS-
# TH

# 🚤 ระบบเก็บขยะลอยนํ้าเคลื่อนที่ด้วยพลังงานแสงอาทิตย์
> โครงงานพัฒนาเรือหรือแพเก็บขยะอัตโนมัติด้วย ESP32 ขับเคลื่อนด้วยพลังงานแสงอาทิตย์ พร้อมเซนเซอร์กันน้ำสำหรับหลบสิ่งกีดขวาง

---

### 📌 เกี่ยวกับโครงการ
โปรเจกต์นี้ทำขึ้นเพื่อเป็นส่วนหนึ่งของการศึกษาค้นคว้าอิสระ (IS) ออกแบบมาเพื่อช่วยทำความสะอาดผิวน้ำในคูคลองหรือแหล่งน้ำปิด โดยใช้บอร์ด **ESP32** ควบคุมปั๊มน้ำและเซนเซอร์อัลตราซาวด์ **JSN-SR04T** ในการตรวจจับและหลบหลีกกำแพงอัตโนมัติครับ

---

### 🛠️ อุปกรณ์หลักที่ใช้
* **Microcontroller:** ESP32 (Core 3.x)
* **Sensors:** เซนเซอร์วัดระยะทางกันน้ำ JSN-SR04T จำนวน 4 ตัว
* **Actuators:** ปั๊มน้ำ 12V จำนวน 4 ตัว (ผ่านบอร์ด MOSFET)
* **Power System:** แผงโซลาร์เซลล์ และ Buck Converter 5V (พร้อมตัวเก็บประจุ 470µF)

---

### ⚙️ ฟังก์ชันการทำงานของระบบ
1. **โหมดดูดน้ำ (Hold):** เปิดปั๊มทั้ง 4 ตัวทำงานเป็นจังหวะเพื่อดูดขยะและน้ำเข้าสู่ระบบ
2. **โหมดเคลื่อนที่ (Move):** เดินหน้า/เคลื่อนที่ 8 ทิศทาง หรือระบบเปลี่ยนทิศทางอัตโนมัติเมื่อเจอสิ่งกีดขวาง
3. **ระบบหลบสิ่งกีดขวาง:** ใช้เซนเซอร์ตรวจจับระยะห่างจากตลิ่งหรือกำแพง เพื่อผ่อนแรงหรือดันตัวเรือหนี
4. **ดูสถานะผ่าน Wi-Fi:** เชื่อมต่อ Wi-Fi ชื่อ `ESP32-ST` (รหัสผ่าน `1234567890`) แล้วเข้าเว็บ `http://192.168.4.1` เพื่อดูสถานะแบบเรียลไทม์ได้เลย

---

### 💻 ข้อมูลการอัปโหลดโค้ด
* **โปรแกรมที่ใช้:** Arduino IDE (เลือกบอร์ดเป็น *ESP32 Dev Module*)
* **Serial Monitor:** ตั้งค่าความเร็วที่ `115200`
